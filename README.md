### 🧭 What I'm building

[**QA Orchestrator**](https://github.com/Rbkmen/qa-orchestrator) — an open-source toolkit for structured AI-assisted code and QA reviews. It provides review profiles, evidence utilities, and a local MCP server to help track the review workflow. The AI host examines the evidence and owns the final decision.
