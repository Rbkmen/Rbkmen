## Featured project

### [QA Orchestrator](https://github.com/Rbkmen/qa-orchestrator)

A local MCP server for privacy-aware QA task routing. It helps structure AI-assisted QA reviews and make their scope and evidence easier to track.

My work on QA Orchestrator was selected for the [XERJ Corpus Hub](https://hub.xerj.org/contributors/Rbkmen), where AI agents can search it as a reference implementation.
